## 2. Violation Details

**All 48** are `TIMING-18`: 12 `jtag*_tdo` input pins are missing `set_input_delay`.

Affected pins:

```
jtag1_tdo  jtag2_tdo  jtag3_tdo  jtag4_tdo
jtag5_tdo  jtag6_tdo  jtag7_tdo  jtag8_tdo
jtag9_tdo  jtag10_tdo jtag11_tdo jtag12_tdo
```

48 = 12 pins × 4 (min/max × rising/falling)

## 3. Current Constraints

`system_ps7_0.xdc` (auto-generated by Vivado):

```tcl
current_instance system_i/ps7/inst
create_clock -period 10.000 -name clk_fpga_0 [get_pins {PS7_i/FCLKCLK[0]}]
set_input_jitter clk_fpga_0 0.300
```

`jtag12.xdc` (hand-written): only defines 48 `PACKAGE_PIN` + `IOSTANDARD`, with **no I/O delay constraints at all** ✗

## 4. Why This Happens

`jtag*_tdo` are **input** signals, driven by the TDO of the external JTAG target board. The toolchain needs to know:

- The **arrival time** of these signals relative to `clk_fpga_0` (`set_input_delay`)
- Otherwise it cannot perform setup/hold analysis on the input paths

## 5. Risk Analysis

| Item | Assessment |
|---|---|
| Actual sampling instant | `ph_samp = div + div/2` ≈ 3/4 period |
| TCK period | 100 ns (10 MHz, DIV=5) |
| Sampling margin | ≈ 75 ns |
| External propagation delay | Board-to-board trace on the order of ~2 ns |
| **Actual risk** | 🟢 **Very low** — 75 ns margin at 10 MHz far exceeds the requirement |

**So this is a formal "missing constraint" issue ✗ not a real timing risk ✓**

But adding the constraints would:
1. Eliminate the 48 warnings ✓
2. Let the tool perform complete input path analysis ✓
3. Provide protection if TCK is raised in the future ✓

## 6. Recommended Fix (USER decision)

The user must confirm the **input delay value**.

### Conservative value (recommended)

```tcl
# Append to jtag12.xdc
# TDO input delay: 30% of the 100ns TCK period, covering board-to-board trace + target device TDO output delay
set_input_delay -clock clk_fpga_0 -max 30.000 [get_ports {jtag*_tdo}]
set_input_delay -clock clk_fpga_0 -min  1.000 [get_ports {jtag*_tdo}]
```

### More conservative (if raising to 20 MHz in the future)

```tcl
set_input_delay -clock clk_fpga_0 -max 15.000 [get_ports {jtag*_tdo}]
set_input_delay -clock clk_fpga_0 -min  0.500 [get_ports {jtag*_tdo}]
```

### Or simply waive it (if you do not want to change constraints)

```tcl
create_waiver -of_objects [get_methodology_violations TIMING-18*] \
  -user <username> -description "TDO sampled at 3/4 TCK period, 75ns margin at 10MHz"
```
